## 📄 **Report Writing and Formatting: Format Standards** 

- Preliminary pages from certificate page up to lists of tables/figures/abbreviations should use **Roman numerals (i,ii,..)** 

- From Chapter 1 onward, pages should use **Arabic numerals (1,2..)** 

- Page number should be at the bottom center 

- **Page size and margins:** 

   - A4 size, Margins: Top = 1, Bottom = 1, Right = 1, Left = 1.25 

- **Paragraph style:** Paragraphs should be justified and Line spacing should be 1.5 

- **Font:** Times New Roman, Body text size 12 

- **Heading sizes:** Chapter headings: 16, Section headings: 14, Sub-section headings: 12 and  all headings should be bold 

- **Figures and tables:** Both should be center aligned, Figure caption goes below the figure, Table caption goes above the table, Captions should be bold-font size 12 

## 📄 **Report Writing and Formatting: Plagiarism** 

- **Plagiarism:** Copying content from a source without proper acknowledgment or citation violates academic integrity. 

### **Avoid Plagiarism:** 

- Always follow ethical guidelines when using information from others. 

- Do not copy content without proper acknowledgment. 

- Cite all sources using the appropriate format (IEEE, APA, etc.). 

- Submit only your own original work. 

- Uphold academic honesty and integrity in all your submissions.
